🧱 UNIT 1: OWASP Attacks & Core Principles

1. Saltzer and Schroeder's 4 Core Secure Design Principles:
• Least Privilege: Give only minimum necessary permissions.
• Fail-Safe Defaults: Default to access denied; security is opt-out, not opt-in.
• Separation of Duties: Require multiple identities/conditions for critical operations.
• Complete Mediation: Verify permissions on every single access without caching.
2. Core Vulnerabilities & Mitigations:
• SQL Injection (SQLi): Attacker alters database queries. Fix: Parameterized queries / Prepared Statements.
• XSS (Cross-Site Scripting): Injects malicious JS into client browsers. Fix: Context-aware output encoding & CSP.
• CSRF: Tricks authenticated browser into submitting actions. Fix: Anti-CSRF synchronizer tokens & SameSite cookies.
• Buffer Overflow: Writes past memory bounds. Fix: Bounds checking, safe functions (snprintf), ASLR, Stack Canaries.
3. NIST SSDF (SP 800-218) 4 Practice Groups:
1. PO (Prepare the Organization) • 2. PS (Protect the Software) • 3. PW (Produce Well-Secured Software) • 4. RV (Respond to Vulnerabilities).
